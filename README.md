# Portal Por Onde Começar?

Estrutura estática leve para publicação no **GitHub Pages**.

## Como atualizar o conteúdo sem mexer no layout
Edite apenas os arquivos dentro da pasta `data/`:
- `dicionario.json`: Verbetes e categorias do Dicionário Marxista.
- `biblioteca.json`: Textos iniciais e catálogo da Biblioteca do Glossário.
- `direitos.json`: Orientações do Guia Trabalhista e Previdenciário 2026 por categoria.
- `coletivos.json`: Coletivos virtuais, movimentos sociais e Cobre Seu Político.
- `midia.json`: Portais de notícias e diretório de canais (WhatsApp, YouTube, Instagram).

## Publicação no GitHub Pages
1. Suba esta pasta para um repositório no GitHub.
2. Acesse **Settings > Pages**.
3. Em **Build and deployment**, selecione a branch `main` e a pasta `/ (root)`.
